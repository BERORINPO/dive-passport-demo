# 名簿の見本の作り方（申込書 1 枚 → 見本を返す）

お店が「架空の人で書いた申込書の写真」を送ってきたとき、REDUX の画面そのものでそのお店の名簿の見本を作り、3 日以内に返す手順。
本番のお店（D1・Access）には触らない。手元で `tools/serve-dist.mjs --real-ai` を動かし、写真の読み取りだけ本物の Claude API を呼ぶ。

予行: 2026-11-02 に 2 回。1 回目は見本の写真 f2、2 回目は健康の欄の位置が違う手書き風の申込書（架空）。どちらも 8 項目を正しく読んだ（和暦の生年月日・令和の取得年も西暦に直した）。写真を入れてから PDF ができるまで、画面の操作は約 5 分。AI の読み取りは 1 回約 3 秒・1 円未満。

## 約束（お店への案内文に書いたこと）

- 写真は米国 Anthropic の AI が読む。見本を返したら、写真はこちらの控えも消す（Gmail の転送メールをごみ箱からも、手元の写真も）
- 本物のお客さんの申込書が届いたら、AI に送らずに消して、お店に知らせる（顔写真・実在しそうな住所と電話・手書きの署名があれば本物を疑う。迷ったら送らない）
- 見本では潜水場所・ガイド・健康の欄は空。健康は「紙の申込書」と出る

## 道具で作る（ふつうはこちら）

`tools/sample-roster.playwright.js` が下の手順 3〜6 を通しでやる（2026-11-02、手書き風の申込書で確かめた）。CONFIG の店名・写真・四角を書き換え、Playwright MCP の `browser_run_code_unsafe` に `filename` で渡す（MCP が読めるのは C:\dev の下だけ。リポジトリのまま渡せる）。

1. 道具を起動する（手順 2）
2. `STEP: 'mask'` で走らせる → `mask.png` を見て、健康の欄（質問の文の頭の字も）が隠れているか確かめる。この回は名簿を道具に書き戻さない
3. `STEP: 'send'` で走らせる → AI が読み、PDF ができる。返り値の `shopOk`・`peopleOk` が両方 true か、`reading` が写真と合っているかを見る
4. 道具を止める（手順 8）

AI が「健康の情報が見えた」と答えたら PDF は作らずに止まる。四角を広げて mask からやり直す。

## 手順（手で作るとき）

1. 届いた写真を手元に保存する（リポジトリの外。例: スクラッチのフォルダ）。本物の申込書でないか、ここで見る
2. 店の名前を入れて起動する。鍵は `CLAUDE_WORKER_API_KEY`（`ANTHROPIC_API_KEY` にはしない）。SHOP_NAME の名前が名簿の「事業者」に出る
   ```
   node tools/build-site.mjs
   SHOP_NAME="〔お店の名前〕" node tools/serve-dist.mjs 8107 --real-ai
   ```
3. **前の見本を開いたことの無いブラウザ**で http://localhost:8107 を開く（Playwright なら `browser.newContext()` の新しい窓。下の「前の見本を混ぜない」）。「予約と名簿」で次を順に押す
   - 健康の質問（お店ごと）→「紙の申込書で聞く」
   - AI の読み取り →「本物にする」
   - 「電話の予約」→ 時刻だけ入れて（代表者は「申込書の見本」）予約を入れる
   - 「今日の名簿」→「名簿の取り込み」→「申込書を撮る」→ 写真を選ぶ
4. 黒い四角をそのお店の書式の健康の欄に合わせる。初めの四角は見本の書式（健康の欄が下の帯）の位置なので、書式が違えば「最後の四角を消す」で消し、健康の欄の上をなぞって四角を作る。**質問の文の頭の字が端から出ていないか**見る（予行 2 回目で 1 回目の四角は左の 1〜2 字が出ていた。足りなければもう 1 つなぞって足す）。「確かめた」に印 →「AI に送る写真を作る」→「この写真を AI で読む」
5. 「名簿に入れる」→「あとで確かめる」（▲未確認の印を残す。お店が確かめる所が見えるのが見本の中身）
6. 「今日の名簿」→「名簿を印刷」の画面を PDF にする。**「印刷する」は押さない**（ブラウザの印刷の窓が開き、自動操作が止まる）。Playwright なら:
   ```js
   await page.emulateMedia({ media: 'print' });
   await page.pdf({ path: 'roster-sample.pdf', format: 'A4', landscape: true, printBackground: true });
   ```
7. PDF を返信に付けて返す。本文に書くこと: 読めた所と ▲未確認 の所の見方、潜水場所・ガイド・健康を空にした理由、送ったあと写真を消すこと（文は omnes-demand の F_回覧と申込書1枚の文面.md の 5 節、メイ PASS 済み）
8. 道具を止め、ブラウザの窓を閉じる（名簿はこの 2 つの中だけにあり、閉じると消える）。写真と PDF の手元の控えを消し、Gmail の転送メールをごみ箱からも消す

## 前の見本を混ぜない

名簿はブラウザ（localStorage）と道具（見本の D1）の両方にあり、つながると互いに写し合う。道具だけ起動し直しても、前の見本を開いたブラウザがつながると、前の人とお店の名前が道具に戻ってくる（予行 2 回目で、1 回目の「見本 健二」と別の店の名前が見本に混ざった）。

- 見本ごとに、道具を止めて起動し直し、**新しいブラウザの窓**（Playwright の新しい context。保存の無い窓）で開く
- アプリの中のブラウザ（Claude のブラウザの窓）で 8107 を開かない。preview_start も起動と同時にそこで開くので使わず、端末から起動する
- 作った PDF の「事業者」と人数を、返す前に見る（1 人・そのお店の名前）

## 気をつけること

- 「お客さんに聞くリンク」「自動の連絡」は押さない（メールは送らずに端末に出るだけだが、見本には要らない）
